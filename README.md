# 🏞️ Destinos Turísticos de Nicaragua / Tourist Destinations of Nicaragua

A simple static website built with **vanilla HTML, CSS and JavaScript** showcasing different tourist destinations across Nicaragua.  
This was one of my first projects (2019) and includes my own photographs taken during my travels.

## ✨ Project Overview

The site presents several well-known destinations across different departments of Nicaragua, including:

- **Managua** – Tiscapa Lagoon, Chocoyero Reserve, Masachapa & Pochomil  
- **Chinandega** – Playa Corinto  
- **Masaya** – Laguna de Apoyo, Laguna de Masaya  
- **Granada** – Isla Zapatera  
- **Carazo** – Cascadas y senderos  
- **Matagalpa** – Cerro Musún  
- **Región Autónoma del Caribe Sur** – El Tortuguero, Bluefields  
- **Río San Juan** – El Castillo, Boca de Sábalos  

All photographs on the site were taken during my personal trips.
